Last updated: 14 October 2026

Diamond Calc offers a 7-day free trial so you can try every feature before paying. Because the subscription is a digital product delivered instantly (the access code is issued as soon as payment succeeds), the following policy applies.

Refunds

  • Duplicate payment for the same purchase: refunded in full.
  • Payment taken but no code received and we are unable to deliver a working code within 3 working days: refunded in full.
  • Request within 3 days of purchase where the code has not been activated on any phone: refunded in full.
  • Once a code has been activated, the subscription is not refundable, except where required by law.

How to request

Contact us on WhatsApp or email with your Razorpay Payment ID and the email used for the purchase. Approved refunds are made to the original payment method within 5–7 working days.

Cancellation

The subscription does not renew automatically, so there is nothing to cancel. Access simply ends on the expiry date unless you renew.
